# Directorio del Sector Musical de Bogotá

MVP para GitHub Pages: directorio + filtros + mapa interactivo alimentado desde `data/directorio.xlsx`.

## Estructura

- `index.html`
- `style.css`
- `app.js`
- `data/directorio.xlsx`

## Publicación

Subir todos los archivos respetando la estructura de carpetas y activar GitHub Pages desde:

Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

La página quedará disponible en la URL de GitHub Pages del repositorio.

## Matriz

Para actualizar los registros, reemplazar `data/directorio.xlsx` manteniendo los nombres de las columnas.

Nota: en una versión pública real conviene separar los datos internos (correo, teléfono, dirección exacta) de los datos que se muestran públicamente.
